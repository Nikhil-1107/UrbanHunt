# Urban Hunt

Urban Hunt is a Django-based real estate web application designed to connect property buyers, sellers, and admins in a simple and modern marketplace experience.

## About the Project

Urban Hunt allows users to:
- Browse available properties
- View property details
- Save favorite listings
- Contact sellers through inquiries
- Manage property listings as a seller
- Administer users, properties, and inquiries

The project is built with Django and uses a responsive template-based frontend to provide a smooth experience across devices.

## Project Theme

The visual style of the application is centered around a modern real estate aesthetic with clean, professional colors.

### Primary Colors
- Dark Blue: #1E3A5F
- Light Blue: #4F8FCB
- White: #FFFFFF
- Soft Gray: #F4F5F7
- Accent Orange: #F59E0B

### Suggested UI Style
- Clean and minimal layout
- Strong contrast for readability
- Modern card-based property presentation
- Friendly and professional dashboard experience

## Tech Stack

- Python
- Django
- SQLite
- HTML / CSS / JavaScript
- Bootstrap-style responsive UI

## Project Structure

- core/ - main application logic, models, views, templates, and forms
- urban_hunt/ - project settings and routing
- media/ - uploaded property images and documents

## Getting Started

1. Clone the repository
2. Install dependencies
3. Run database migrations
4. Start the development server

Example:

```bash
python manage.py migrate
python manage.py runserver
```

## Purpose

Urban Hunt aims to simplify property buying and selling by offering a reliable, user-friendly platform for managing real estate listings and communication.
